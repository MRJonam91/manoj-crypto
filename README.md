# Crypto

Una base per consultare e analizzare informazioni sul mercato delle criptovalute.

## Stato del progetto

`app-esistente/` contiene una versione precedente dell’interfaccia e del backend PHP. I file di configurazione privati sono esclusi: prima dell’uso occorre verificare le fonti, le chiavi e la configurazione del server.

## Dati e fonti

Non è incluso uno storico di mercato verificato. I dati e le analisi hanno finalità informative e non costituiscono consulenza finanziaria.
